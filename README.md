# Сайт-портфолио

Публичная ссылка: https://model-portfolio-sonyazelenuk.netlify.app

## Добавить фотографию

**С телефона:**

1. Открыть squoosh.app в браузере телефона, загрузить фото.
2. Выбрать формат WebP, качество около 82, размер — чтобы длинная сторона
   была 1600 px, скачать результат.
3. Назвать файл `NN-имя.webp`, где `NN` — двузначный номер. Номер задаёт
   порядок в галерее: `01-` идёт первым. Расширение обязательно `.webp` —
   файл с другим расширением сборка молча проигнорирует, и фото просто не
   появится на сайте.
4. Положить в папку `photos/` — через веб-интерфейс GitHub с телефона это
   Add file → Upload files.
5. Сайт пересоберётся сам за пару минут.

**С компьютера:** вместо squoosh.app можно сжать пачкой — скрипт сам
приведёт фото к WebP и ширине 1600 px:
`python3 tools/prepare_photos.py "media files" photos` — дальше те же шаги
3–5 (имя файла и загрузка).

## Поменять параметры или контакт

Всё лежит в `content.js`: имя, город, ссылка на Telegram, восемь строк
компкарта. Править прямо в GitHub, кнопкой с карандашом.

## Откатить неудачную правку

На странице коммита в GitHub нажать Revert. Сайт вернётся к предыдущему
состоянию автоматически.

## Пересобрать медиа локально

```bash
python3 tools/prepare_photos.py "media files" photos   # фото
bash tools/prepare_video.sh "media files/showreel.mp4" # видео и постер
node build-photos.js                                   # список фото
python3 -m http.server 8000                            # посмотреть локально
```
