# Spec — сайт-портфолио модели

## PRD

**Название проекта:** Одностраничный сайт-портфолио начинающей модели

**Описание:** Стильный одностраничный сайт в тёмной editorial-эстетике: видео-баннер на весь экран, фотогалерея, компкарт с параметрами и кнопки прямой связи с моделью. Решает проблему отсутствия профессиональной онлайн-презентации: сейчас модели нечего отправить агентствам и кастинг-директорам одной ссылкой, а фото разбросаны по мессенджерам и соцсетям.

**Целевая аудитория:** Агенты, кастинг-директора, фотографы и бренды, которые оценивают модель по ссылке — чаще всего с телефона. Вторичный пользователь — сама модель и администратор сайта (обновление фотографий).

**Ключевая проблема:** У модели нет единой точки, где собраны лучшие фото, видео и параметры; портфолио приходится пересылать файлами, это выглядит непрофессионально и неудобно для получателя.

**Устройства:** Веб, mobile-first (основной сценарий — просмотр с телефона); корректное отображение на десктопе обязательно.

**Бюджет на хостинг:** 0 ₽/мес — только бесплатные сервисы (GitHub + Netlify, план Б — Cloudflare Pages; бесплатный поддомен вида `имя.netlify.app`).

**Дедлайн MVP:** 2–3 недели (ориентир — первая неделя сентября 2026).

**Ключевые уточнения:**
- В hero-баннере — только имя модели, латиницей, красивым элегантным шрифтом (serif типа Cormorant / Playfair Display — финальный выбор по прототипу). Без роста и других параметров.
- Контакты — только самой модели (агента пока нет); структура должна позволять позже добавить блок агента без переделки.

## Requirements

### MVP (обязательно для первой версии)

- Hero-баннер с предзаписанным видео на весь экран (muted, autoplay, loop, постер-кадр на время загрузки)
- Имя модели латиницей поверх баннера, элегантный serif-шрифт
- Фотогалерея: адаптивная сетка, фото из папки `/photos` репозитория
- Лайтбокс: открытие фото на весь экран по тапу, свайп-листание между фото
- Плавные анимации появления секций при скролле (CSS + Intersection Observer)
- Компкарт: рост, объёмы, размеры одежды и обуви, цвет волос и глаз
- Кнопки связи с моделью: Telegram (`t.me/…`) и звонок (`tel:+…`), без форм и бэкенда
- Mobile-first вёрстка + корректное отображение на десктопе
- Тёмный editorial-стиль: почти чёрный фон, контрастная типографика, много воздуха
- Сжатые медиа: видео ≤6 МБ (H.264 MP4, 1080p, без звука), фото в WebP ~200–400 КБ
- Автосборка списка фото через GitHub Action → `photos.json` (убирает ручной шаг и ошибки с именами файлов)
- Деплой на Netlify — рабочая публичная ссылка (план Б хостинга — Cloudflare Pages)

### Nice-to-have (добавим потом)

- Двуязычность RU/EN с переключателем в шапке (тексты в одном JSON-словаре)
- Блок контактов агента (когда появится агент)
- OpenGraph-превью: карточка с фото при отправке ссылки в Telegram/WhatsApp
- Свой домен вместо `имя.netlify.app`
- Раздел с дополнительными видео (backstage, catwalk)
- Скачиваемый компкарт в PDF одной кнопкой

### Процесс разработки (снижение рисков AI-генерации)

- Одна правка = один коммит с понятным названием; откат любой поломки — одна команда
- Правки проверяются на deploy preview (временная ссылка на ветку) с телефона до публикации в основную версию
- Чек-лист ручной проверки после каждой правки: баннер играет → галерея открывается → свайп листает → компкарт читается → кнопки Telegram и звонка работают

### Принцип разреза MVP

MVP = минимальный путь пользователя: агент открыл ссылку с телефона → увидел баннер с именем → посмотрел фото → узнал параметры → нажал «написать в Telegram» или «позвонить». Всё, что не лежит на этом пути, — в Nice-to-have.

## Tech Stack

Принцип выбора: минимум движущихся частей. Код правится через AI-генерацию, поэтому каждая лишняя технология — лишний слой для ошибок. Одностраничник со статичным контентом = «нулевой» стек без фреймворков и сборщиков.

| Компонент | Технология | Почему для этого проекта | Бесплатно? |
|---|---|---|---|
| Разметка и стили | HTML + чистый CSS | Один экран, пять секций — фреймворк добавил бы сборку и точки отказа без пользы. Кастомная editorial-типографика точнее делается руками в CSS. ИИ пишет HTML/CSS практически безошибочно | Да |
| Интерактив | Vanilla JS (без библиотек) | Весь JS: лайтбокс, свайп, Intersection Observer для анимаций, подстановка фото из `photos.json` — ~150 строк. Один файл легко целиком отдавать Claude для правок | Да |
| Шрифты | Self-hosted `.woff2` в репозитории (кандидаты — из Google Fonts, см. ниже) | Красивый serif для имени латиницей + кириллица для остального текста. Self-hosting сразу: быстрее и нет зависимости от доступности Google Fonts из РФ | Да |
| Репозиторий и хранилище фото | GitHub | Папка `/photos` в репо = хранилище фото; обновление через commit, история версий позволяет откатить неудачную замену | Да |
| Хостинг | Netlify (план Б — Cloudflare Pages) | Подключается к GitHub-репо, автодеплой при каждом пуше: «закинула фото → закоммитила → сайт обновился» из коробки; deploy preview для проверки правок до публикации. Cloudflare Pages — без лимита трафика и стабильнее из РФ; переезд ~30 мин, т.к. стек статический | Да, 100 ГБ трафика/мес (Cloudflare — без лимита) |
| Сжатие видео | ffmpeg | Ужать видео до ≤6 МБ без звука — одна готовая команда | Да, open source |
| Сжатие фото | Squoosh (squoosh.app) или cwebp | Squoosh — сайт с ползунком качества для разовых фото; cwebp — пакетная обработка папки командой | Да |
| Разработка | Claude Code | Плоский статический проект из 3–4 файлов — идеальный размер контекста; PRD + requirements лежат в репо как ТЗ | По подписке |

**Решение по Bolt/Lovable:** не использовать. Они генерируют React-проект со сборкой — лишний вес для этого сайта, экспортировать и упрощать мучительно. Прототип и разработка — сразу в Claude Code.

**Итог по деньгам:** 0 ₽/мес; единственная будущая опциональная трата — свой домен (nice-to-have).

### Шрифты: план по уровням

Имя в баннере — латиницей, поэтому дисплейный шрифт не обязан поддерживать кириллицу. Кириллица нужна только для основного текста: компкарт, подписи, кнопки.

**Уровень 1 — Google Fonts с хорошей кириллицей:**
- Prata — тонкий контрастный serif («обложка Vogue»)
- Oranienbaum — изящный, чуть винтажный serif
- Tenor Sans — элегантный гротеск для параметров
- EB Garamond, Lora — спокойная классика
- Базовые кандидаты для имени: Cormorant, Playfair Display

**Уровень 2 — любой сторонний шрифт через self-hosting:**
файл `.woff2` кладётся в репозиторий и подключается в CSS через `@font-face`. Требование: лицензия на веб-использование. Безопасные источники бесплатной кириллицы — Paratype (линейка PT), шрифты под OFL (open font license). Пиратские сборники коммерческих шрифтов не использовать.

**Процесс выбора:** в прототипе шрифт задаётся одной CSS-переменной; собирается экран-«примерочная» — имя и фрагмент компкарта в 3–4 шрифтовых парах рядом, выбор глазами по живому макету.

### Риски стека и их снижение

1. **Обновление завязано на одного человека и git.** Снижение: автосборка `photos.json` через GitHub Action — в MVP; модель при необходимости может загружать фото через веб-интерфейс GitHub с телефона (Add file → Upload). Эскалация при реальной потребности — Decap CMS поверх того же репо.
2. **AI-правки без тестов могут незаметно ломать соседние фичи.** Снижение: мелкие коммиты, deploy preview, чек-лист ручной проверки после каждой правки.
3. **Зарубежный бесплатный хостинг: доступность из РФ и лимит трафика.** Снижение: self-hosted шрифты, обязательный постер-кадр в баннере, план Б — Cloudflare Pages (без лимита трафика, стабильнее из РФ).
