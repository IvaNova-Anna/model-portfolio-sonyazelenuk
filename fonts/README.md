# Fonts

Self-hosted `.woff2` files (latin subset only — the site's text is English-only).
All four families are Google Fonts, licensed under the **SIL Open Font License 1.1** —
self-hosting is permitted.

Font selection (Task 4, Step 7) was deliberately skipped: the choice of display
typeface is the site owner's aesthetic call and will be decided by comparing all
four candidates directly on the finished page. All four files are kept in this
directory until that decision is made.

Currently wired in `style.css`:
- `--font-display` → Cormorant Garamond
- `--font-body` → Tenor Sans
